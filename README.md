# gezi-packs

Gezi uygulaması için çevrimdışı şehir paketleri. Sadece açık lisanslı veri içerir.

- Harita: [Protomaps](https://protomaps.com) — © [OpenStreetMap katkıcıları](https://www.openstreetmap.org/copyright) (ODbL)
- Mekân ve şehir verisi: Wikidata (CC0), OpenStreetMap (ODbL)
- Fotoğraflar: Wikimedia Commons — her fotoğrafın yazarı ve lisansı `places.json` içinde yer alır
